# AKS GPU, KVM, sandbox and stack verification, 2026-10-20

End-to-end verification of `main@2e67fae` and the four fixes in this branch on
a seven-node Azure Kubernetes Service (AKS) cluster with an NVIDIA A100 80GB
PCIe GPU, five Intel VT-x KVM nodes and Istio ambient mesh. This pass starts
with the paused GPU checks from [EKS-PAUSED-2026-10-18.md](EKS-PAUSED-2026-10-18.md)
and the H6 GPU items in [LEFTOVERS.md](../LEFTOVERS.md), then exercises the
KVM/Firecracker microVM scale, `TestLoad` (`DESIGN.md` §12–§14), M4 rolling
upgrade/HA/N-1, multi-service task environments, PR #101/103 cluster controls,
real CLI agent trajectory readers under the sandbox egress allowlist,
TraceSource connectors, PostgreSQL PITR, OTLP redaction, 3-node NATS HA, and
post-`v0.3.0` (`#110`–`#119`) CPU checks.

No cluster credentials, endpoints or private hostnames are included. All
owned test namespaces, Helm releases, CRDs and GPU reservations were removed
at the end of the run.

- Kubernetes `v1.36.4`, Ubuntu 24.04.5 LTS, kernel `6.8.0-1070-azure` (`amd64`),
  `containerd://2.3.6-1`, Azure CNI overlay (`network-policy: none`), Istio
  ambient (`istiod`, `ztunnel`, `istio-cni-node`).

  (`disk.csi.azure.com`), `azurefile-csi` / `azurefile-csi-premium`

    `vmx` and `/dev/kvm`, taint `CriticalAddonsOnly=true:NoSchedule`).
